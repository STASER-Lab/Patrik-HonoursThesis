`Patrik-HonoursThesis` is a software repository inside the STASER-Lab organization designed to evaluate distributed document layouts for software repository activity. Using public GitHub activity data from GH Archive, the research project implements several document layouts and configurations in Elasticsearch. These alternatives are evaluated and compared across storage requirements, data loading time, query performance, and computational resource consumption.

To learn more about STASER-Lab, visit https://staser-lab.github.io

# Documentation

Documentation can be found online at https://staser-lab.github.io/Patrik-HonoursThesis/. The documentation covers technical details, background information, and usage examples. It is built from `documentation/` in this repository.
