`Patrik-HonoursThesis` is a software repository within the STASER-Lab organization, developed to evaluate document storage layouts in distributed systems for software repository activity. Using public GitHub activity data from GH Archive, this research project implements several document storage layouts and configurations in Elasticsearch. These alternatives are evaluated and compared in terms of storage requirements, data loading time, query performance, and computational resource consumption.

To learn more about STASER-Lab, visit https://staser-lab.github.io.

## Documentation

The documentation is available at https://staser-lab.github.io/Patrik-HonoursThesis/. It covers technical details, background information, and usage examples. The documentation is generated from the files in `documentation/`.
